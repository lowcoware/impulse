# Политика безопасности

## Область

impulse — это тулинг для разработчика, не сетевой сервис: Markdown-файлы
скиллов плюс горстка локальных Node.js hooks (`hooks/`) и линт-скриптов
(`scripts/`), которые выполняются внутри вашей же сессии Claude Code /
Cursor / Codex / Antigravity. Здесь ничего не поднимает сервер, не
обращается к endpoint, подконтрольному impulse, и не собирает телеметрию.

## Как сообщить об уязвимости

Используйте приватный репортинг уязвимостей GitHub, а не публичный issue:
откройте Security Advisory во вкладке Security репозитория, либо сразу
идите на `github.com/lowcoware/impulse/security/advisories/new`. Advisory
остаются приватными до выхода фикса.

В скоуп входит: всё, что заставляет hook выполнить непредусмотренный код,
прочитать или вытащить данные за пределы текущего workspace, либо
затронуть сессию за пределами своего репозитория. Укажите, какой
hook/скрипт, ваш CLI + ОС, и минимальный репро, если он у вас есть.

## Позиция hooks: никогда не блокировать

Каждый hook (`hooks/impulse-activate.js`, `hooks/impulse-mode-tracker.js`,
`hooks/impulse-subagent.js`) написан так, чтобы молча отказывать: нет файла
конфига, директория не git, пробел в пути или неожиданная ошибка — и hook
делает no-op вместо того, чтобы бросить исключение. Сломанный hook не
должен блокировать вашу сессию никогда. Наткнулись на случай, когда hook
блокирует, виснет или останавливает Claude Code от продолжения работы —
это баг: заводите как обычный issue, если только это не вопрос инъекции
или эксфильтрации, тогда используйте канал advisory выше.

## Никаких секретов в репозитории

Ничего под `skills/`, `hooks/`, `scripts/` или `shared/` не должно
содержать живой credential, API-ключ или токен, даже как "пример". Нашли
такое — сообщите через канал advisory, чтобы это вычистили из истории git
до раскрытия: один последующий коммит сам по себе не убирает секрет из
истории.

## Поддерживаемые версии

Только последний тегированный релиз. Это скилл-сьют, а не сервис —
LTS-ветки нет.
