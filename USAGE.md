# Использование — impulse в разных CLI

Установка — в `INSTALL.md`; здесь про то, как этим пользоваться после
того, как поставил. Полный список скиллов и их команд — в `README.md` или
через `/impulse-help`.

## Как это вообще работает

Скилл подключается двумя способами:

1. **По description.** Роутер CLI сам сверяет твой промпт с триггерами
   скилла и подтягивает нужный. Работает в любом из четырёх prompt-роутинг
   CLI, даже с голой копией папок. OpenCode устроен иначе — там явный тул
   `skill`, агент сам решает вызвать его по описанию (детали в разделе
   OpenCode ниже), но конечный эффект тот же.
2. **Слэш-командой `/impulse-*`.** Только Claude Code и только когда сьют
   стоит как нативный плагин. У остальных CLI слэш-команд сьюта нет.

Режим `blitz|medium|hardcore` — отдельная механика поверх скилла, есть
только у `impulse-backend` и `impulse-frontend` и только в плагине Claude Code.
Вне плагина флага режима нет, но эффект тот же, если назвать режим прямо в
промпте: "review this Go service in hardcore mode" подтянет hardcore-гайд
`impulse-backend`, просто без трекинга состояния и без бейджа в statusline.

## Claude Code

Нативный плагин — самый богатый путь: слэш-команды, hooks, бейдж в
statusline, стейтфул-переключатель режима.

- Позвать скилл: командой (`/impulse-review`, `/impulse-security`) или просто
  опиши задачу — автоподключение по description тоже работает.
- Режим: `/impulse-backend hardcore`, `/impulse-frontend blitz`. Выключить —
  `stop impulse` или `normal mode`.
- Statusline показывает состояние: `[IMPULSE:BE:BLITZ]`, `[IMPULSE:FE]`,
  `[IMPULSE:BE+FE:HARDCORE]`.
- Дефолты — `~/.config/impulse/config.json` (`defaultMode`, `docstringLang`,
  `coverageTarget`, `core`).

Голая копия (без плагина, установка через `scripts/install.js`): работает
только автоподключение по description. Ни команд, ни hooks, ни флага
режима — режим называй словами в промпте.

## Cursor

Cursor читает `.claude/skills/` нативно. Скиллы подключаются по
description (тип правила Agent-Requested) или явным упоминанием.
Слэш-команд сьюта и флага режима нет.

Как звать: опиши задачу так, чтобы сработал нужный триггер — "проверь этот
Go-дифф на оверинжиниринг" подтянет `impulse-review`, "собери страницу на
Nuxt, режим hardcore" — `impulse-frontend` с архитектурным заходом (режим
словами).

## Codex CLI

Ставится в `.agents/skills/`. Подключение по description. Слэш-команд нет.

Хочешь, чтобы гайд скилла загружался принудительно, а не роутился по
промпту, — добавь строку-указатель в `AGENTS.md` своего проекта. Это
отдельный, встроенный в ядро Codex механизм инъекции контекста
(конкатенация root -> leaf, лимит по умолчанию 32 KiB).

## Antigravity

Ставится в `.agents/skills/` — тот же путь, что у Codex на project scope.
Подключение по description. Слэш-команд нет. Для форс-инъекции правил —
`.agents/rules/*.md` (workspace) или `~/.gemini/GEMINI.md` (глобально) и
`AGENTS.md` (лимит 12000 символов).

## Что переносится, а что нет

| | Claude Code (плагин) | Claude Code (копия) | Cursor | Codex | Antigravity |
|---|---|---|---|---|---|
| Автоподключение по description | да | да | да | да | да |
| Слэш-команды `/impulse-*` | да | нет | нет | нет | нет |
| Режим blitz/medium/hardcore | да | нет (словами) | нет (словами) | нет (словами) | нет (словами) |
| Hooks | да | нет | нет | нет | нет |
| Бейдж statusline | да | нет | нет | нет | нет |

Подробности установки и путей на каждый таргет — `INSTALL.md`.
