# Assessment: modes, complexity ladder, scoring, complex-site playbooks

From nexu-io/open-design web-clone (Apache-2.0), re-expressed for the impulse suite.
Used before cloning (to scope honestly), after cloning (to grade), and to explain
"how far can this site be cloned" without hand-waving.

## Clone modes

| Mode | Goal | When |
|---|---|---|
| Faithful clone | Keep original source/layout/interaction as-is | Legit source found, single-file site, studying a hard frontend technique |
| Visual clone | Looks close, internals replaceable | No source, commercial site, componentized rebuild |
| Rebrand | Keep the site's rhythm and visual grammar, swap in own content | Turning a reference site into your own product page |
| Teardown | Don't rebuild yet — establish the real implementation first | WebGL/Canvas/complex interaction, contradictory secondhand analyses |

Default when the user just says "clone this": **faithful clone** — fidelity is the
point. Do not silently downgrade to visual clone because the original is a
commercial site: real fonts, real images, real color values first; record any
license/brand risk in `./NOTES.md` as a "replace before deploy" list and leave the
replacement decision to the user. Only go visual/rebrand when the user explicitly
wants "my own site out of this".

## Complexity L1-L6

| Level | Type | Typical signals | Usual fidelity | Default boundary |
|---|---|---|---|---|
| L1 | Static HTML/CSS | Little JS, no framework, few pages | 90-98% | Near pixel-level; asset copyright is separate |
| L2 | CMS / corporate content site | Many pages, CMS-generated, forms/news/regions | 70-90% | Front is clonable, CMS backend is not |
| L3 | React/Vue/Next content frontend | Hydration, chunks, routing, API-fed content | 65-90% | Data/APIs replaced with local JSON stand-ins |
| L4 | Animation-heavy brand site | GSAP, Lenis, scroll choreography, video masks | 50-80% | Hero visuals recoverable, micro-interactions often approximate |
| L5 | WebGL/Canvas/Three.js | Shaders, physics, post-processing, GPU assets | 30-95% | High with source; without it, teardown first, then commit |
| L6 | SaaS / e-commerce / logged-in systems | Accounts, payments, orders, permissions, search | Presentation layer only | Server-side business logic is never cloned |

## Pre-clone assessment (write it before promising anything)

```markdown
## Pre-clone assessment
- Complexity level: L1-L6
- Recommended mode: faithful / visual / rebrand / teardown
- High-fidelity parts:
- Approximated or substituted parts:
- Not cloned:
- Main risks: license / assets / auth / APIs / performance / WebGL / responsive
```

## Post-clone scoring

Each dimension 0-5. Only give scores that a screenshot, source line, or browser
run can back — computed evidence outranks eyeballing.

| Dimension | 5 | 3 | 1 |
|---|---|---|---|
| Source evidence | Real source or full static assets; key claims carry file:line | Runtime recon + asset capture | Mostly eyeballing and inference |
| Structure | IA, section order, breakpoints all match | Main sections match, details merged/dropped | Only the broad style survives |
| Visual | Fonts, spacing, colors, image ratios closely match | Main visuals close, some proportions differ | Reads as a different design |
| Motion/interaction | Scroll, hover, video, canvas/WebGL behavior close | Core interactions only | Essentially static |
| Responsive | Desktop/tablet/phone all verified, no breakage | 1-2 widths verified | Mobile visibly broken |
| Functional | Nav, forms, media, links, local run all work | Main browse path works | Dead links and errors |
| Content swap | Own content in, replacement map clear | Partial, original residue remains | Heavy original copy/brand residue |
| Legal/deploy risk | License clear, trackers stripped, asset boundary explicit | Risks recorded, unresolved | Risks unknown |

## Deliverables per clone project

- `./NOTES.md` (always): source info + license (verified, not assumed), stack,
  pre-clone assessment, run instructions, original-vs-clone comparison table,
  scores, replacement map, verification checklist, honest list of what could NOT
  be verified. Never fabricate "drag works" when synthetic PointerEvents
  (`isTrusted=false`) can't trigger it.
- `./TEARDOWN.md` (complex interactive sites): pillar-by-pillar technical
  teardown, every claim tagged with an evidence grade and file:line — see
  `effect-extraction.md`.
- `RECON/`: screenshots (1440/768/390 original + clone), recon JSON, route maps,
  interaction evidence, asset manifest, network fixtures, sourcemap results,
  visual-diff metrics, baseline replays.
- `./CLONE_REPORT.md` (when reporting outward): generated by `compare-recon.mjs`.
- `./CLONE_AUDIT.md` (before any deploy): generated by `audit-clone.mjs` — trackers,
  original-brand residue, TODOs, risky external URLs; `--recon --strict` adds
  hard fidelity gates (exit 2 on failure).
- Keep the original source as a read-only baseline (`index-original.html`); never
  edit it in place. Kill local server processes when done.

## L4 playbook — animation-heavy brand sites

1. Recon confirms the libraries (GSAP/Lenis/ScrollTrigger) — clone the same
   scroll feel, not native scrolling with the same colors.
2. `interaction-probe.mjs` captures scroll-sequence screenshots; mid-scroll
   states (sticky-header shadow, entrance trigger points) must match too.
3. Rebuild timeline by timeline; approximations get named in `./NOTES.md`.

## L5 playbook — WebGL/Canvas/Three.js

Route through `effect-extraction.md` (evidence grades, baseline gate, runtime
capture). Single-file native sites: byte-for-byte retention IS the most faithful
clone. No source found: runtime frame capture, never visual guesswork.

## L6 playbook — SaaS / e-commerce / logged-in systems

Clone presentation and demoable flows only; never real accounts/payments/orders.

1. Publicly-served logged-in pages: confirm authorization and privacy boundary first.
2. `network-capture.mjs` saves XHR/fetch responses as fixtures.
3. Split APIs: content / search-filter / user-state / transactional writes.
4. Content APIs get local JSON stand-ins; write APIs get mock success/failure only.
5. Keep empty, loading, error, and no-permission states — not just the happy path.
6. `audit-clone.mjs` sweeps external links, brand residue, trackers.

## Multi-page / CMS sites

1. Grab sitemap, nav, footer, main templates first (`route-crawl.mjs`).
2. Clone representative templates only: home, list, detail, search, contact.
3. Repeated content is data-file-generated, not hand-written per page.
4. CMS backend is never cloned; local JSON/Markdown substitutes for editability.

## Success criteria

- Original evidence complete: screenshots, recon JSON, network + asset manifests.
- Clone runs locally, console/page errors zero or explained.
- Report scores structure/visual/interaction/responsive/functional boundaries.
- Audit finds no trackers, no brand residue, no unexplained external-URL risk.
- Real backends, proprietary APIs, copyrighted assets: boundaries stated, not blurred.
